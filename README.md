# 🧬 ארכיון השחזורים

אתר אחד שמאחד את כל השחזורים האינטראקטיביים, לכל המקצועות.

## איך זה בנוי

הרעיון המרכזי: **התוכן והמנוע מופרדים.**

עד היום כל שחזור היה קובץ HTML שלם — השאלות היו 5% מהקובץ, וכל השאר CSS ו-JavaScript
שהשתכפלו מחדש בכל פעם. לכן אי אפשר היה לאחד אותם: לא היה מה לאחד, רק ערימת תאומים.

עכשיו:

```
exams/               ← התוכן. כל שחזור = קובץ JSON קטן עם השאלות בלבד.
  manifest.json      ← רשימת המבחנים. נבנה אוטומטית, לא נוגעים בו ידנית.
  courses.json       ← כרטיסי המקצועות: שמות, תאריכי מבחנים, קישורי לומדות.
  biochem-b-2026-moed-a.json
  ...
assets/app.js        ← המנוע. קורא את כל השחזורים ומרנדר אותם.
assets/cloud.js      ← הגשר היחיד לענן (Supabase) — התחברות וסנכרון.
assets/style.css     ← העיצוב (עם tokens.css + components.css).
index.html           ← המעטפת.
sync.js              ← בודק תקינות ומעדכן את המניפסט. רץ לפני כל דחיפה.
repeats.js           ← מזהה שאלות שחוזרות בין מחזורים ובונה את ה-High Yield.
guides/              ← הלומדות — סיכומי HTML עצמאיים (נבנים עם guides/_template).
anki/                ← חפיסות אנקי מוכנות להורדה (anki-build.py + anki-index.json).
supabase/            ← המיגרציות של הענן + יומן מה כבר רץ (MIGRATIONS-RUN.md).
PROMPT.md            ← התבנית לייצור שחזור חדש (או: הסקיל import-shichzur).
*.py                 ← סקריפטי עבודה: new-course, lomda-ask, anki-ask, explain-ask.
```

מכאן, כל שחזור חדש מרוויח אוטומטית כל שיפור שנעשה במנוע — בלי לגעת בשחזורים הישנים.

## הפעלה מקומית

לחיצה כפולה על **`start.command`**. זה פותח את הארכיון בדפדפן.

> אי אפשר פשוט לפתוח את `index.html` בלחיצה כפולה — הדפדפן חוסם קריאת קבצים
> מהדיסק (`file://`) מטעמי אבטחה, והמבחנים לא ייטענו. לכן יש את `start.command`.

## הוספת שחזור חדש

1. פותחים צ'אט עם קלוד ומדביקים את התוכן של `PROMPT.md` יחד עם חומר הגלם.
2. שומרים את ה-JSON שחוזר בתיקייה `exams/` בשם `<id>.json`.
3. מריצים:
   ```bash
   node sync.js
   ```
   הסקריפט בודק שהכול תקין — שאין תשובה נכונה שמצביעה על מסיח שלא קיים,
   שאין מזהה כפול, שיש טקסט לכל שאלה — ומעדכן את המניפסט לבד.
4. מרעננים את האתר. השחזור שם.

## מבנה שאלה

```json
{
  "q": "טקסט השאלה",
  "opts": ["מסיח 1", "מסיח 2", "מסיח 3"],
  "a": 1,
  "topic": "שם הנושא — עקבי בין המבחנים, ממנו נבנים הפילוח והתרגול לפי נושא",
  "explain": "הסבר שמלמד למה הנכונה נכונה, ואז פסילה קצרה לכל מסיח",
  "source": "אופציונלי — מאיזה שחזור השאלה הגיעה",
  "note": "אופציונלי — קיצורים, או ציון שהשאלה מבוססת גרף",
  "image": "assets/img/<קיצור מזהה המבחן>-q7.jpeg",
  "table": { "headers": ["א", "ב"], "rows": [["1", "2"]] }
}
```

`a` הוא **אינדקס מבוסס-אפס**: התשובה הראשונה היא `0`. זו הטעות הכי קלה לעשות,
ולכן `sync.js` בודק אותה.

`explain` הוא השדה שהלומד באמת קורא, ויש לו תבנית: הסבר מלמד לתשובה הנכונה,
ואחריו משפט קצר לכל מסיח שמתחיל ב"המסיח ה\<סידורי\>". האתר מפרק את זה לתבנית
מוצגת עם בולט ממוספר לכל מסיח. **הכללים: [`QUESTION-STANDARD.md`](QUESTION-STANDARD.md).**

שם קובץ התמונה הוא **קיצור** של מזהה המבחן ולא המזהה המלא
(`electro-2021-mA-q34.png` לשחזור `electro-2021-moed-a`) — כשמוסיפים תמונה,
להסתכל על מה שכבר קיים באותו מבחן ולהמשיך את אותו קיצור.

## הוספת מקצוע חדש

לא רק קובץ שאלות: כרטיס מקצוע, רשימת נושאים סגורה, מפת חומרים וסיכום מלא.
הסדר והחובות: **[NEW-COURSE.md](NEW-COURSE.md)**.

## מה יש באתר

- **ספרייה** — כל המבחנים מקובצים לפי מקצוע, עם הציון שלך בכל אחד.
- **תרגול מעורב** — בורר לפי נושא וכמות, עם לייטנר (חזרה מרווחת) מאחורי הקלעים:
  "חדשות", "הטעויות שלי", "לוודא שאני עדיין יודע".
- **סימולציית מבחן** — טיימר, בלי משוב תוך כדי, ציון והסברים רק בסוף.
- **לומדות** (`guides/`) — סיכום מלא לכל קורס בשלושה מצבי קריאה, עם "מה
  באמת נשאל" בתוך כל נושא.
- **מפת החומרים ועץ הידע** — מה ללמוד, מאיפה, ומה מצב הכיסוי שלך.
- **i❤️Shinun** — שינון צד-מול-צד בלי מסיחים: היפוך, כסה-וגלה, מבחן קצר, שמע.
- **אנקי** — חפיסות מוכנות להורדה לכל קורס.
- **דף נוסחאות** בתוך השאלה (אלקטרו), דיווח 🚩 על טעות בשאלה, וסקר משוב.

ההתקדמות נשמרת בדפדפן (`localStorage`) **וגם בענן**: מאז 22/07/2026 האתר סגור
מאחורי התחברות Google, וההתקדמות מסתנכרנת בין מכשירים דרך Supabase. הגשר היחיד
לענן הוא `assets/cloud.js`; `app.js` פונה אליו רק כ-`window.Cloud?.…`, ולכן אם
הענן כבוי או נכשל — האתר עובד בדיוק כמו קודם, מקומית. פתיחה מקומית
(`localhost`) לא מדברת עם מסד הייצור כלל; `?cloud=1` מדליק אותו במפורש.

כל אחד רואה את ההתקדמות של עצמו בלבד. לוח הבקרה (`#/admin`) מציג **אגרגטים
בלבד**, עם רצפת מינימום של 10 עונים לכל נתון.

## העלאה לאוויר

האתר כבר חי ב-GitHub Pages. הזרימה: מריצים `node sync.js` (בונה את המניפסט,
מחדש את קבצי ה-High Yield וחותם את גרסאות הנכסים ב-`index.html`), מקמטים,
ודוחפים ל-`main`. **הדחיפה ידנית בכוונה** — היא קובעת מתי שינוי עולה לאוויר.

```bash
node sync.js && git add -A && git commit && git push
```

מכאן, הוספת שחזור היא `git push` — וכולם רואים אותו מיד.
