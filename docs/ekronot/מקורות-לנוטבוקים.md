# מקורות לנוטבוקים — מה להעלות לכל מקצוע

כל הנתיבים יחסית ל-`דרייב רפואה מחזור נ״ב/שנה ב - מחזור נ״ב/1 - עקרונות המדע הבסיסיים חלק א׳+ ב׳/`.

**הכלל:** סיכום-שדרה אחד + סיכומי דין פרי שיעור-שיעור + השחזור הרלוונטי.
לא להעלות מצגות מרצים ולא ספרי לימוד — הם מנפחים את הנוטבוק ומורידים את איכות הציטוטים.

## שני נוטבוקים נוספים ששווים בפני עצמם

**מתכונת הבלוק** — מה שמלמד איך המבחן החדש באמת נראה:
- `שחזורים מתכונת חדשה/בלוק יסודות חלק א - מחזור נא מועד א.pdf`
- `סיכומים - מחזור נ״א/דין פרי/שאלות מהבוחן - שיעורים 1-3.pdf`
- `סיכומים - מחזור נ״א/דין פרי/שאלות מהבוחן – שיעורים 1-4.pdf`
- `מיפוי שחזורים רלוונטים .pdf`

**סיכומי דין פרי המלאים** — כל שמונת המקצועות ב-`סיכומים - מחזור נ״א/דין פרי/`.
