## מה חדש באתר (הדלת השביעית: „🎮 לשחק עם זה”)

בעמוד של כל מקצוע בעקרונות המדע יש עכשיו אזור „🎮 לשחק עם זה”. כדאי לנסות אחד מכל סוג:

| כלי | מה עושים | דוגמה לנסות |
|---|---|---|
| 🔑 מפתח ההגדרה | תיק נפתח ברמז; בוחרים איזו בדיקה להריץ (עולה נקודות), ומזהים מבין בני המשפחה | מיקרו → „מעגל האבחון” → התיק של המורסה בירך |
| 🩺 מקרים מתגלגלים | תיק שמתפתח, החלטה אחרי החלטה, לוח אבחנה מבדלת | פרמקו → „חקלאי בן 42 אחרי ריסוס” |
| 🧠 i❤️Shinun | עובדות לבעל-פה, לפי מקצוע; מצב מבחן עם מסיחים מאותה משפחה | פיזיולוגיה → i❤️Shinun → 📝 מבחן |
| 🖱️ משחק על איור | לחיצה על רישום אק״ג / קריאת אילן יוחסין | פיזיולוגיה → „אק״ג — לחצו על הרישום”; גנטיקה → „פתרו את האילן” |
| 🎛️ סימולציות | סליידרים, גרף חי, „נסו את זה” | פרמקו → עקומת ריכוז-זמן (הורד את הפינוי בחצי) |
| 🧮 תרגילי חישוב + 📖 נוסחאות | מספרים חדשים בכל פעם, פתרון שלב-שלב | גנטיקה → סיכון לזוג (אח בריא של חולה) |
