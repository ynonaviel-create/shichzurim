# קורס חדש בפקודה אחת — הצינור המלא

הכללים המלאים: `NEW-COURSE.md`. הסקיל הזה הוא **סדר הפעולות והאוטומציה** —
מה רץ, באיזה סדר, ומה הנקודה היחידה שבה עוצרים לינון.

## עקרונות

- **נקודת אישור אחת בלבד: רשימת הנושאים.** ינון ביקש לא להישאל שוב ושוב —
  כל שאר ההכרעות הן שלך, לפי הסטנדרטים הכתובים. חריג: תוכן שעולה לאוויר
  לעיני 116 משתמשים עובר את המדגם שלו (NEW-COURSE שלב 7) — אבל את זה
  מציגים לו פעם אחת בסוף, לא תוך כדי.
- **strict:true מהרגע הראשון** — new-course.py עושה את זה לבד. קורס שבור
  לא עולה.
- **קורס באמצע בנייה לא מפיל את הארכיון:** שלד המפה חי ב-`exams/_staging/`
  (ש-sync לא סורק) עד שיש שאלות מתויגות.

## הצינור

### 1. הכרטיס (מכני — סקריפט)
```bash
python3 new-course.py init <id> --name "<שם>" --icon <אימוג׳י> --blurb "<שורה>"
```

### 2. רשימת הנושאים — ⏸️ העצירה היחידה
לגזור 10–25 נושאים קנוניים מהסילבוס/מערכי השיעור, למלא ב-`topics` של
הכרטיס, **ולהציג לינון לאישור** (בהיר, בלי ז׳רגון — הוא מאשר פעם אחת).
שם נושא = עוגן לכל החיים: תרגול, מפה, לומדה, אנקי, סימולציות. שינוי שם
אחרי פרסום שובר guid-ים של אנקי וקישורי סימולציה.

באותה הזדמנות: `dates` (מועדי בחינה), `about`, `code`, ואם מלווים את
הקורס מתחילתו — `teaching` (start + נושאי כל שבוע; מדליק את "השבוע בקורס").

### 3. השלדים (מכני — סקריפט)
```bash
python3 new-course.py scaffold <id>
```
מייצר: שלד מפה (יחידה לכל נושא) + שלד לומדה מלא (build.py — עיצוב, הקראה,
מצבים, תרגילים, הכול מהתבנית).

### 4. השאלות
- שחזורים אמיתיים: הסקיל `import-shichzur`.
- בנקי תרגול: לפי `QUESTION-STANDARD.md` + `PROMPT.md` (כולל hotspot
  לקורסים חזותיים). דו״ח ההטיה של sync חייב לצאת נקי.
- כשיש שאלות מתויגות: להעביר את המפה מ-`exams/_staging/` ל-`exams/`.

### 5. מילוי המפה
תדירויות אמיתיות מספירת שאלות, מקורות, נקודות "מה באמת נשאל" (עם qids
אמיתיים — sync אוכף), מלכודות, סרטונים מאומתי-תמלול, blocks אם יש simExam.

### 6. תוכן הלומדה
```bash
python3 lomda-ask.py <id> --all     # טיוטות מהנוטבוק, מסומנות 🤖
```
ואז סוכני `write-study-guide` (אחד לכל בלוק) מאמתים ומחליפים כל טיוטה
בתוכן סופי + איורים. בסוף: רישום המסמך ב-`DOCS` של
`guides/_template/inject.py` (modes/qa/shinun) והרצת inject — הוולידציה
האוטומטית רצה שם.

דורש: נוטבוק לקורס בטבלת `NOTEBOOKS` של `anki-ask.py` (חשבון shichzurim52
בלבד) עם ההרצאות/מצגות/סיכומים בפנים.

### 7. שכבות לפי אופי הקורס
i❤️Shinun (מונחים רבים) · אנקי (`anki-ask.py` → `anki-build.py`) ·
סימולציות/דף נוסחאות (דורשים קוד — NEW-COURSE שלב 6) · רישום ב-repeats.js
כשיהיה מחזור שני.

### 8. סגירה
`node sync.js` בלי ❌ → בדיקת דפדפן (שאלה מכל בנק, הלומדה בשלושת המצבים,
מובייל+כהה) → **מדגם לינון** → קומיט. דוחפים רק אחרי sync.
